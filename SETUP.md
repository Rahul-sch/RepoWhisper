# Development setup

```bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cd ../frontend
./setup_xcode.sh
swift build
```

Run the Xcode app to exercise integration. On first use, select a repository folder and approve microphone access. Boss Mode and Explain Visible also require Screen Recording permission in System Settings.

The backend intentionally fails closed unless the app supplies an allowlist file, socket path, data directory, and random authentication token. Those runtime values are generated by `BackendProcessManager`; they do not belong in `.env`.
