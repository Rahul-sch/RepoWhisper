# Optional backend configuration

RepoWhisper works locally without a cloud account. Copy `env.template` to `.env` only when overriding defaults.

```dotenv
GROQ_API_KEY=
WHISPER_MODEL=tiny.en
EMBEDDING_MODEL=all-MiniLM-L6-v2
DEBUG=false
```

Socket, authentication, data-directory, and allowlist values are generated by the macOS app for each launch. Never commit provider keys or generated runtime tokens.
